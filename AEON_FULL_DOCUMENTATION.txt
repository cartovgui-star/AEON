                      4. TRADING ENGINE SPECIFICATIONS
═══════════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────────────┐
│                    CONFLUENCE SCORING SYSTEM                                 │
└─────────────────────────────────────────────────────────────────────────────┘

The trading engine uses a weighted confluence score to determine trade quality:

                    ┌─────────────────────────────────┐
                    │     CONFLUENCE WEIGHTS          │
                    ├─────────────────────────────────┤
                    │  Core Technicals      60%      │
                    │  Market Structure     20%      │
                    │  Derivatives          20%      │
                    └─────────────────────────────────┘

CORE TECHNICALS (60% Weight):
┌──────────────────┬──────────────────────────────────────────────────────────┐
│ RSI (14)         │ <30 = Oversold (Long), >70 = Overbought (Short)         │
│ MACD (12,26,9)   │ Crossovers + Histogram expansion                        │
│ Bollinger Bands  │ Band touches (20,2), Squeeze detection                  │
│ EMA Stack        │ 9/21/50 alignment, Pullback entries                     │
│ Stochastic       │ <20 = Long, >80 = Short, Crossovers                     │
│ ATR              │ Stop loss calculation, Volatility filter                │
└──────────────────┴──────────────────────────────────────────────────────────┘

MARKET STRUCTURE / SMC (20% Weight):
┌──────────────────┬──────────────────────────────────────────────────────────┐
│ HH/HL Pattern    │ Higher Highs/Higher Lows = Uptrend                      │
│ LL/LH Pattern    │ Lower Lows/Lower Highs = Downtrend                      │
│ BOS              │ Break of Structure                                       │
│ CHoCH            │ Change of Character                                      │
│ FVG              │ Fair Value Gaps (imbalance zones)                       │
│ Order Blocks     │ Institutional entry zones                               │
│ Liquidity Sweeps │ Stop hunts at key levels                                │
└──────────────────┴──────────────────────────────────────────────────────────┘

DERIVATIVES / ORDER FLOW (20% Weight):
┌──────────────────┬──────────────────────────────────────────────────────────┐
│ Funding Rate     │ >0.1% = Short bias, <-0.1% = Long bias                  │
│ Open Interest    │ OI spike = Potential reversal                           │
│ Long/Short Ratio │ >1.5 = Crowded longs (short), <0.67 = Short (long)      │
│ CVD              │ Cumulative Volume Delta for buyer/seller pressure       │
└──────────────────┴──────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────┐
│                      TRADE STYLES                                            │
└─────────────────────────────────────────────────────────────────────────────┘

Trade style is DYNAMICALLY assigned based on ATR volatility:

┌─────────┬────────────┬─────────────┬───────────────┬────────────────────────┐
│ Style   │ Timeframes │ Leverage    │ ATR Trigger   │ Hold Duration          │
├─────────┼────────────┼─────────────┼───────────────┼────────────────────────┤
│ SCALP   │ 5m, 15m    │ 50-200x     │ ATR > 2%      │ Minutes to 4 hours     │
│ DAY     │ 1h, 4h     │ 20-75x      │ ATR 1-2%      │ Hours to 24 hours      │
│ SWING   │ 4h, 1d     │ 10-25x      │ ATR < 1%      │ Days to 1 week         │
└─────────┴────────────┴─────────────┴───────────────┴────────────────────────┘

DYNAMIC STYLE LOGIC (from autonomous_trader_v2.py):

    if atr_pct > 2.0:        # High volatility
        → SCALP (quick trades, high leverage)
    elif atr_pct > 1.0:      # Medium volatility  
        → DAY (moderate holds)
    else:                     # Low volatility
        → SWING (longer positions)


┌─────────────────────────────────────────────────────────────────────────────┐
│                    POSITION SIZING                                           │
└─────────────────────────────────────────────────────────────────────────────┘

KELLY CRITERION FORMULA:
    f = (p × b - q) / b
    
    Where:
    p = Win probability
    q = Loss probability (1 - p)
    b = Average win / Average loss ratio

POSITION SIZE RANGE:
    ┌──────────────────────────────────────────┐
    │  Minimum Position:    $500               │
    │  Maximum Position:    $2,500             │
    │  Base Position:       $1,000             │
    │  Risk Per Trade:      1% max             │
    └──────────────────────────────────────────┘

POSITION SCALING (50/50 Entry):
    ┌──────────────────────────────────────────┐
    │  Initial Entry:  50% of calculated size  │
    │  Scale-In:       50% on confirmation     │
    │  Confirmation:   Price moves 0.3-1.5%    │
    │                  in favorable direction  │
    └──────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────┐
│                    RISK MANAGEMENT                                           │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────┬───────────────────────────────────────────────────────┐
│ Auto-Blacklist      │ Pairs with <30% win rate after 10 trades             │
│ Cooldown Period     │ 4 hours after losing trade on same pair              │
│ Volatility Filter   │ Skip if ATR > 2x 20-period average                   │
│ Max Open Trades     │ 15 positions maximum                                 │
│ Min Confidence      │ 80% threshold for trade entry                        │
│ Min Confirmations   │ 3+ data sources must agree                           │
│ Trailing Stop       │ Moves to breakeven at +1% profit                     │
│ Momentum Exit       │ Early exit if RSI diverges while in profit           │
